# Qualification Profiles

Profiles are domain-specific instruments over a domain-neutral CQS contract.

Available reference profiles:
- engineering.v1
- mathematical.v1
- scientific.v1
- educational.v1
- security.v1
- research.v1

A profile defines required evidence types and evaluates only preserved evidence. It does not mutate authority.

Future profiles should define:
- benchmark validity rules
- reproducibility thresholds
- independence dimensions
- security requirements
- acceptable verification mechanisms
- domain-specific failure semantics
- NOT_MEASURED conditions
