# MANIFEX Integration Boundary

CQS should integrate with MANIFEX through explicit contracts.

Construction:
Discovery -> Mechanism -> Implementation -> CQS

Availability:
CQS Qualification -> Capability Genome projection

Composition:
Capability Genome -> Intelligence Router -> Intelligence Plan

Authorization:
Intelligence Plan -> Authority Plan -> Authorization -> Capability Lease

Execution:
Lease -> Engineering Runner -> Observation -> Evidence

CQS must never:
- issue authorization
- expand capability leases
- modify the constitution
- select itself as verifier
- convert FAILED or NOT_MEASURED evidence into success
- rewrite historical records
